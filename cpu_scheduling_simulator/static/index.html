04 QUICK REFERENCE

Understand the algorithms

Use these notes to prepare for your practical demonstration and viva.

01Simple queue

First Come, First Served

Processes run in the order they arrive. It is easy to implement, but a long process can make shorter processes wait.

Order: Arrival time → oldest first
02Shortest burst first

Shortest Job First

Among the processes that have arrived, the one with the smallest burst time runs next. This version is non-preemptive.

Choice: Minimum burst among ready jobs
03Time slicing

Round Robin

Each ready process receives up to one time quantum. Unfinished processes return to the back of the ready queue.

Run time: min(quantum, remaining burst)
